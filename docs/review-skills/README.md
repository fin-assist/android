# Навыки PR-ревью (FIN-421)

Перед содержательным ревью выберите по diff минимальный достаточный набор, прочитайте файлы `SKILL.md`
из текущего коммита PR и выполните применимые процедуры. Название без чтения и применения не считается
использованием навыка. При изменении нескольких областей выберите навыки для каждой; весь каталог по умолчанию
читать не нужно. Обязательные проверки и полномочия заданы в корневом `AGENTS.md`.

| --- | --- |

| [codebase-design](vendor/engineering-suite/codebase-design/SKILL.md) | Изменения границ модулей, связности и публичных интерфейсов. |

SQL и PostgreSQL навыки поставляются только в Go-бэкенд; в конкретном ревью они применяются лишь к
затронутым SQL/хранению/транзакциям. Навыки Android поставляются только в Android-репозиторий.
Для `contracts` применимы общие навыки и Go-навыки при изменении handwritten Go или генераторов.


В сводке укажите названия применённых навыков, если применяли их.

## Применение в контексте PR

Последние согласованные решения владельца и правила `AGENTS.md` и `docs/` имеют приоритет над
общими рекомендациями навыков. Навык не вводит требований сверх правил репозитория.
В частности, SQL-навыки не служат основанием предлагать запрещённые репозиторием ограничения,
триггеры, функции или `pg_partman`, либо объявлять такой запрет вредной конвенцией.

Для `code-review` применяются оси Standards/Spec и подходящие проверки. Точка отсчёта — merge-base
целевой ветки PR и его текущего коммита; спецификация — FIN-задача из описания PR и последние
уточнения владельца; стандарты — `AGENTS.md` и `docs/`. Шаги установки issue tracker,
`/setup-matt-pocock-skills`, интерактивные вопросы и обязательный запуск sub-agent здесь не требуются.
Формат результата задают `AGENTS.md` и инструмент ревью, включая правило о названиях применённых навыков.

## Доступность и ограничения

Все материалы лежат в `docs/review-skills/vendor/` этого репозитория. Читайте их по относительным
путям из PR head; локальные установленные плагины владельца не требуются. Если файл недоступен,
продолжайте обязательные проходы из `AGENTS.md`. Не приписывайте навыку выполненные проверки,
если его инструкция не была прочитана. Навык не разрешает merge, публикацию, доступ к секретам или UI-тесты.


## Источники, лицензии и обновление

Точные upstream URL, ревизии, исходные уведомления и состав выбранных файлов приведены в
[PROVENANCE.md](PROVENANCE.md). Для Engineering Suite сохранены лицензии пакета и авторов
выбранных upstream-навыков.

При обновлении сверяйте закреплённый источник, лицензии и уведомления; переносите `SKILL.md`
и все реально используемые материалы, включая пути в backticks, и проверяйте разрешение ссылок.
Обновляйте каталог одним PR. Изменение Go-шаблона не обновляет другие репозитории автоматически.
Проверка сценариев выбора — [acceptance.md](acceptance.md).
